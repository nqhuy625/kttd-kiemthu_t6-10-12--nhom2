

\# Bài kiểm thử tự động Web - Tuần 4



\## 1. Giới thiệu

Bài kiểm thử sử dụng Selenium và Pytest để kiểm tra trang web https://the-internet.herokuapp.com/.



\## 2. Cài đặt

Cài đặt Python và Google Chrome trước.



Mở CMD tại thư mục này và chạy lệnh:



```bash

python -m pip install -r requirements.txt

```



\## 3. Chạy kiểm thử

Chạy lệnh:



```bash

python -m pytest test\_smoke.py -v

```



\## 4. Kết quả

Nếu kiểm thử thành công, CMD sẽ hiển thị `1 passed`.
