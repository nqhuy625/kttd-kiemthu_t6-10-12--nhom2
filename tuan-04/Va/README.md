\# Bài tập kiểm thử phần mềm - Tuần 4



\## 1. Mục tiêu

Thực hành kiểm thử tự động bằng Python, Selenium WebDriver và pytest.



\## 2. Công cụ sử dụng

\- Python

\- Selenium

\- pytest

\- Google Chrome



\## 3. Cài đặt môi trường

Mở CMD tại thư mục gốc của dự án và chạy:



```bash

python -m venv .venv

.venv\\Scripts\\activate

python -m pip install -r requirements.txt

```



\## 4. Chạy kiểm thử

Chạy toàn bộ bài kiểm thử tuần 4 bằng lệnh:



```bash

python -m pytest -v tuan-04\\test\_smoke.py

```



\## 5. Nội dung kiểm thử

\- Kiểm tra trang chủ mở được và có tiêu đề mong đợi.

\- Kiểm tra thao tác chọn checkbox trên trang kiểm thử.



\## 6. Ảnh minh chứng

Ảnh chụp kết quả kiểm thử được lưu trong thư mục `tuan-04/anh/`.
